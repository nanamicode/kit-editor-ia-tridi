01

O QUE ESTA AULA RESOLVE

O Lúcio mostra duas portas para usar o Claude além do app. Na extensão do Chrome, ele conta
que o Claude abre o navegador e faz o que não dá para fazer por API, como entrar na área de
membros, criar as capas dos módulos e subir as aulas. Na aula, ele pede ao Claude para
entender a oferta de duas páginas de vendas públicas (uma com VSL e outra de texto), e a aba
do Chrome fica com o nome Claude e uma borda laranja enquanto ele lê. Depois mostra o VS
Code com o plugin do Claude, mas avisa que, para quem não é programador e está na Fábrica,
o app do Claude é a melhor opção. O recado final é instalar a extensão do Chrome, deixar o
navegador em segundo plano e trabalhar normalmente.

IDEIA CENTRAL

O Claude abre o navegador e faz por você o que não dá para
fazer por API; o VS Code é opcional e o app do Claude
continua sendo o caminho principal da Fábrica.

02

O QUE VOCÊ APRENDE

01  Para que serve a extensão do Chrome

    Conectada na mesma conta do Claude, ela abre o navegador e faz o que ele não
    consegue fazer por API. O Lúcio usa isso para entrar na área de membros, criar as
    capas dos módulos e subir as aulas, porque as plataformas de venda de produtos
    digitais não têm API. Ele resume: o Claude ajuda, seja por API, por linha de comando ou
    abrindo o navegador.

02  Como instalar

    Instale primeiro o Google Chrome. Depois procure por Claude extensão, na Chrome Web
    Store ou no site do Claude, clique em adicionar e conecte na sua conta. Quando você
    tem o Claude Code instalado no mesmo computador do navegador, os dois se
    comunicam diretamente.

03  Ler páginas de vendas

    Abra as páginas, peça para o Claude entender a oferta e ele navega por elas, inclusive
    assistindo ao VSL. O Chrome não precisa estar em primeiro plano. Enquanto o Claude
    acessa, a aba mostra o nome Claude e fica laranja; se você fechar a aba, a leitura
    termina.

04  Onde o Chrome ajuda na Fábrica

    Ele complementa a navegação na web quando o Claude não acha a informação de
    outra forma: página, oferta, promessa e público; perfil do Instagram (com você logado
    no navegador, ou por API); e a Biblioteca de Anúncios da Meta, quando você pede para
    pesquisar anúncios de um produto, também com você logado.

05  VS Code: opcional

    É um software que você baixa. Abra uma pasta, instale o plugin do Claude e o chat
    aparece dentro dele, com a mesma interface e os modos do app. Também dá para usar
    pelo terminal, digitando claude. O Lúcio avisa: o VS Code é para quem já é
    desenvolvedor. Para criar criativos na Fábrica, use o app do Claude.

06  Rotina de trabalho

    Abra a pasta da Fábrica, deixe o Chrome em segundo plano e comece a trabalhar. Tudo
    que o Claude fizer no navegador é como se fosse você pesquisando no Google.

GLOSSÁRIO

Extensão   Pequeno programa que se instala no navegador, como o Chrome, para ele
           ganhar funções novas.

API        Conexão direta entre programas. Quando a plataforma não tem, o Claude pode

           abrir o navegador e fazer o trabalho como você faria.

VSL       Vídeo de vendas, que o Claude consegue assistir pela extensão do Chrome.

VS Code   Software para quem desenvolve, onde o Claude pode ser usado por plugin ou
          pelo terminal. Quem está na Fábrica não precisa dele.

Terminal  Janela em que se digita comandos, como claude, para iniciar o Claude por
          linha de comando.
