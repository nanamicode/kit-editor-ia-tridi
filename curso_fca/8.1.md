🎯 Sobre esta aula

Este módulo é 100% mão na massa: o objetivo é você sair com a sua fábrica instalada no computador, funcionando e pronta para usar. Para chegar lá, o Lúcio explica como o Claude Code funciona, os planos de assinatura e a instalação, que é o ambiente.

Você baixa o app oficial do Claude, cria a conta e instala a extensão do Google Chrome. Depois entende o plano: o grátis não tem Claude Code, o Pro é o recomendado para começar, e o uso funciona em janelas de 5 horas, com uma janela total semanal que reinicia em dia e hora fixos.

Por fim, vê na tela de Uso como acompanhar o consumo, inclusive a janela própria do Fable, que é um modelo maior e mais caro.

✅ O que você leva desta aula
A fábrica roda dentro do Claude Code

Extensão do Claude no Google Chrome
Plano com Claude Code
Janelas de 5 horas e janela semanal
